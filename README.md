# Blackthorn Evidence Lab

A 40-minute classroom evidence-analysis game for Grades 10 and 12.

## Hosting
GitHub Pages publishes the main branch root. Edit index.html and push to main to update. No build or dependencies are required.

## Student use
Progress is stored locally in the browser. Students download their case report for submission. No central score collection or multiplayer server is included. The teacher lesson is not part of this repository.
